# Plasma-Physics-Code

Projects

1. Landau Damping
  * Solve a (1+1)d model of the linearised kinetic equation
  * Includes Lenard-Bernstein collision operator
  * Demonstrates Landau damping and free energy evolution with collisional effects
2. Two Stream Instability
  * Solve a (1+1)d Vlasov_Poisson equation
  * Demonstrates the two-stream instability
3. Grad Shafranov solver (WIP)
  * Uses a finite element method to solve the Grad Shafranov equation
  * Then implements a Picard iteration for the non-linear part of the equation
  * Also want to add least square optimization to determine the current profile from boundary data to reconstruct the              magnetic field
